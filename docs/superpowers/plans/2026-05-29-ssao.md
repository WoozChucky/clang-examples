# SSAO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add classic screen-space ambient occlusion: a mid-pipeline pass (after G-buffer, before lighting) that darkens the ambient term where nearby geometry occludes it, with an engine-tier toggle + tunables.

**Architecture:** `SsaoRenderPass` is an ordered `IRenderPass` (like `ShadowDepthPass`) inserted between `GBufferFillPass` and `LightingRenderPass`. It reads the G-buffer world Normal/Position SRVs, runs an AO sub-pass + a box-blur sub-pass into Renderer-owned R8 targets, and `LightingRenderPass` multiplies its ambient term by `GetSsaoTexture()` (gated by a `uSsaoEnabled` CB flag). Settings live in the engine tier, mirroring the shadow-settings plumbing.

**Tech Stack:** C++23, GLM (RH, ZO), NVRHI, DXC (inline HLSL), nlohmann::json, Dear ImGui.

**Spec:** `docs/superpowers/specs/2026-05-29-ssao-design.md`

- [ ] **Step 4: Implement the helpers.** Create `src/engine/src/rendering/SsaoMath.h`:

```cpp
#pragma once

#include <cstdint>
#include <cmath>
#include <glm/glm.hpp>

// Fixed 16-sample cosine/quadratic-weighted hemisphere kernel for SSAO. The kernel lives in
// TANGENT space (+Z = surface normal); the shader rotates it into world space per pixel. The
// CPU side computes it once and uploads it to the AO shader's constant buffer.
struct SsaoKernel {
    static constexpr int Count = 16;
    glm::vec3 Samples[Count];
};

// Deterministic kernel (no RNG so it's reproducible + unit-testable): points spread over the
// +Z hemisphere, lengths quadratically pulled toward the origin so more samples cluster near
// the surface (the standard SSAO weighting). Uses a fixed low-discrepancy-ish set via golden-angle
// spiral; deterministic for a given Count.
inline SsaoKernel MakeHemisphereKernel() {
    SsaoKernel k;
    const float golden = 2.39996323f; // golden angle (radians)
    for (int i = 0; i < SsaoKernel::Count; ++i) {
        const float t = (static_cast<float>(i) + 0.5f) / static_cast<float>(SsaoKernel::Count);
        const float z = t;                       // cos of polar angle in [0,1] -> +Z hemisphere
        const float r = std::sqrt(1.0f - z * z); // ring radius on the hemisphere
        const float phi = static_cast<float>(i) * golden;
        glm::vec3 dir(r * std::cos(phi), r * std::sin(phi), z);
        // Quadratic length bias toward the origin (more samples close to the surface).
        float scale = static_cast<float>(i) / static_cast<float>(SsaoKernel::Count);
        scale = glm::mix(0.1f, 1.0f, scale * scale);
        k.Samples[i] = dir * scale;
    }
    return k;
}

// True when the stored surface depth is IN FRONT of the sample (closer to the camera) by more
// than `bias`. View-space Z is negative (RH, looking down -Z), so "closer to camera" = larger
// (less negative) Z. occluderViewZ > sampleViewZ + bias  =>  occluded.
inline bool IsOccluded(float sampleViewZ, float occluderViewZ, float bias) {
    return occluderViewZ > (sampleViewZ + bias);
}

// Range falloff: 1 when the occluder is at the shaded point, ramping to 0 at `radius` and beyond
// (prevents distant geometry from haloing). `dist` = world distance between shaded point and
// occluder surface.
inline float RangeWeight(float dist, float radius) {
    if (radius <= 1e-5f) return 0.0f;
    const float t = glm::clamp(1.0f - dist / radius, 0.0f, 1.0f);
    return t; // linear falloff; smoothstep is a valid evolution
}
```

- [ ] **Step 3: Write `SsaoRenderPass.cpp`.** Mirror `SmaaRenderPass.cpp` structure. Key specifics:

CB struct (matches the AO shader cbuffer; 16-byte aligned):
```cpp
struct SsaoCB {
    glm::mat4 ViewProj;       // world -> clip (project sample points to screen)
    glm::vec4 Kernel[16];     // xyz = tangent-space hemisphere sample, w unused
    glm::vec4 Params;         // x=Radius, y=Bias, z=Intensity, w=Power
    glm::vec4 RtSize;         // xy = (width,height), zw = (1/w, 1/h)
};
```

AO shader (inline HLSL string `SSAO_AO_PS`): full-screen triangle VS (copy SmaaRenderPass's VS pattern). PS:
- `Texture2D uNormal : register(t1); Texture2D uWorldPos : register(t2); SamplerState uPt : register(s3);` + `cbuffer SsaoCB : register(b0)` with the fields above.
- Read `N = uNormal.Sample(uPt, uv).xyz`; if `dot(N,N) < 0.5` return `float4(1,0,0,0)` (sky → no occlusion). `P = uWorldPos.Sample(uPt, uv).xyz`.
- Build per-pixel rotation angle from a screen hash (`frac(sin(dot(uv*RtSize.xy, float2(12.9898,78.233)))*43758.5453)*6.2831853`); build a TBN: pick an arbitrary tangent `T = normalize(cross(N, abs(N.y) < 0.99 ? float3(0,1,0) : float3(1,0,0)))`, rotate T around N by the angle, `B = cross(N,T)`.
- Compute the shaded point's view-space Z once: `viewZ_P = (mul(ViewProj-as-needed))` — simpler: since we only compare *relative* view depth, reconstruct view-space Z via the camera. To keep the shader self-contained, pass the camera **View** matrix too (add `float4x4 View;` to the CB) and compute `viewZ(x) = mul(View, float4(x,1)).z`.
- Loop 16 samples: `S = P + (T*kernel.x + B*kernel.y + N*kernel.z) * Radius`; project `clip = mul(ViewProj, float4(S,1))`; `if (clip.w <= 0) continue;` `ndc = clip.xyz/clip.w`; `uvS = ndc.xy*0.5+0.5; uvS.y = 1-uvS.y;` skip if outside [0,1]; `Pocc = uWorldPos.Sample(uPt, uvS).xyz;` `occZ = viewZ(Pocc); sampZ = viewZ(S);` `range = RangeWeight(length(Pocc - P), Radius)` (inline the linear falloff); `if (occZ > sampZ + Bias) occlusion += range;`
- `occlusion = (occlusion / 16.0) * Intensity; ao = pow(saturate(1.0 - occlusion), Power);` return `float4(ao,0,0,0)`.

Add `View` to the CB struct (`glm::mat4 View;`) — update `SsaoCB` accordingly (place it after `ViewProj`; keep 16-byte alignment — two mat4s are fine).

Blur shader (`SSAO_BLUR_PS`): `Texture2D uAo : register(t1); SamplerState uPt : register(s3); cbuffer { float4 uTexel; }` (xy = 1/size). 4×4 box average of `uAo.Sample(uPt, uv + (x,y)*uTexel.xy).r` for x,y in [-1.5..1.5 stepping 1] (i.e. offsets -1.5,-0.5,0.5,1.5)/size; output `float4(sum/16,0,0,0)`. (Reuse the SsaoCB for `RtSize.zw` as the texel; or a tiny separate CB — simplest: reuse `m_CB`'s `RtSize`.)

`Initialize`: compile the 4 shaders (vs_6_1/ps_6_1) via `m_Renderer->CreateShader`; create a point-clamp sampler; build 2 binding layouts with Vulkan offsets (AO: CB b0, t1 normal, t2 worldpos, s3 sampler; Blur: CB b0, t1 ao, s3 sampler) — globally-unique slots; create `m_CB` (`sizeof(SsaoCB)`).

## Known Risk Notes (concrete)

- **CB alignment:** both `LightFrameCB` (Task 4) and `SsaoCB` (Task 3) must stay 16-byte aligned and match their HLSL cbuffers field-for-field (incl. padding). The plan adds explicit pad ints.
- **View-space Z sign:** RH view looks down -Z, so "closer to camera" = larger (less negative) Z — `IsOccluded`/the shader compare use `occluderViewZ > sampleViewZ + bias`. Keep consistent between `SsaoMath.h` (tested) and the shader.
- **Binding slots:** lighting adds t8 for AO (b0/t1/t2/t3/s4/t5/t6/s7/t8 — all unique for the Vulkan flat binding). SSAO pass uses b0/t1/t2/s3 (AO) and b0/t1/s3 (blur) — unique within each set.
- **Runtime shader compile:** AO/blur + the modified lighting shader compile via DXC at runtime; clean C++ build ≠ shaders compile. The Task 4 manual step is where they're first exercised — watch the console.
